# Tateti

Juego de tateti (ta-te-ti / tres en línea) para dos jugadores, hecho con HTML, CSS y JavaScript puro.

## Cómo jugar

1. Abrir `index.html` en el navegador.
2. Los jugadores se turnan haciendo clic en las casillas (empieza X).
3. Gana quien complete primero una fila, columna o diagonal.
4. "Nueva partida" limpia el tablero; "Reiniciar marcador" pone los puntos en cero.

## Archivos

- `index.html` — estructura de la página
- `style.css` — estilos
- `script.js` — lógica del juego
